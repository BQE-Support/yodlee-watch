# Yodlee Watch

Internal BQE Support page: Yodlee (Orbitus) service requests side by side with their Zendesk tickets, with alerts for status mismatches, replies waiting to be passed on, and requests that have gone quiet.

Live at https://bqe-support.github.io/yodlee-watch/

This repository holds only the page itself. It contains no customer or ticket data: the page loads that after an approved user signs in.
